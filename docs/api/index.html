CO2 fault detection API

Shared functions used by the three experiment notebooks. Inputs, outputs, units and failure cases are documented below each signature. The source is included for inspection.

  • analysis — Tables and plots connecting the saved experiment to the report's conclusions.
  • data — Sensor preparation and causal input construction with shared row eligibility.
  • detectors — Two-sided CUSUM with label-free resets and validation-only calibration.
  • evaluation — Post-inference evaluation using labels that are never inputs to prediction.
  • extraction — Stream the course environmental CSV into the documented long-format input.
  • faults — Reproducible finite additive faults; original references stay outside inference.
  • models — Training-only scaling and the fixed regression and neural-network recipes.
  • project — Portable project paths and explicit records of successfully completed runs.
  • 01_main_experiment — notebook orchestration functions
  • 02_nn_input_comparison — notebook orchestration functions
  • 03_results_analysis — notebook orchestration functions

Study order: main experiment, controlled NN input comparison, then results analysis. CUSUM statistics are not additional CO2 predictions. Simulated faults and passing implementation checks do not establish real sensor health.
